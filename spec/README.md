# 功能规格目录

本目录包含 Beanfun Fork 项目的所有功能规格文档。

## 文档列表

| 文档 | 内容 |
|------|------|
| [overview.md](./overview.md) | 项目概述、架构设计、技术栈 |
| [multi-game-cards.md](./multi-game-cards.md) | 多游戏卡片列表功能规格 |
| [otp-security.md](./otp-security.md) | OTP 安全机制规格 |
| [ui-ux-optimizations.md](./ui-ux-optimizations.md) | UI/UX 优化规格 |
| [interaction-improvements.md](./interaction-improvements.md) | 交互体验改进规格 |

## 阅读建议

1. **新成员入门**: 先阅读 [overview.md](./overview.md) 了解项目整体架构
2. **功能开发**: 根据功能查看对应的规格文档
3. **问题排查**: 结合相关规格文档理解设计意图

## 与 .trae/documents 的区别

- **spec/**: 正式的、整理后的功能规格，面向开发者和维护者
- **.trae/documents/**: 设计过程中的原始文档，包含问题分析、方案对比、决策记录等
