# 多游戏卡片列表功能规格

## 功能概述

以可展开卡片形式展示所有游戏，每个卡片包含完整的游戏操作功能。

## 用户界面

### 卡片布局

```
┌─────────────────────────────────────────┐
│  [设置] [关于]                    [X]   │  ← TitleBar
├─────────────────────────────────────────┤
│                                         │
│  ┌─────────────────────────────────┐    │
│  │ [游戏封面]  游戏名称        [▼] │    │  ← 卡片头部（始终显示）
│  │             已添加 3 个账号      │    │
│  ├─────────────────────────────────┤    │
│  │ 账号列表                         │    │  ← 展开后显示
│  │ - 账号一                    ⋯   │    │
│  │ - 账号二                    ⋯   │    │
│  │ - 账号三                    ⋯   │    │
│  ├─────────────────────────────────┤    │
│  │ [获取 OTP] [启动游戏]            │    │
│  │ 自动粘贴 OTP [开关]              │    │
│  └─────────────────────────────────┘    │
│                                         │
│  ┌─────────────────────────────────┐    │
│  │ [游戏封面]  游戏名称        [▶] │    │  ← 收起的卡片
│  │             未添加账号          │    │
│  └─────────────────────────────────┘    │
│                                         │
└─────────────────────────────────────────┘
```

### 卡片状态

| 状态 | 显示内容 |
|------|----------|
| 收起 | 游戏封面、名称、账号数量、展开箭头 |
| 展开 | 头部 + 账号列表 + OTP区域 + 启动按钮 |

## 功能需求

### FR-1: 游戏列表展示

**描述**: 登录后展示所有游戏的卡片列表

**验收标准**:
- [x] 每个游戏显示为独立卡片
- [x] 卡片显示游戏封面和名称
- [x] 显示已添加的账号数量
- [x] 未设置路径的游戏显示警告

### FR-2: 卡片展开/收起

**描述**: 点击卡片头部可展开或收起

**验收标准**:
- [x] 点击头部切换展开/收起状态
- [x] 展开时加载账号列表
- [x] 同时只能展开一个卡片（可选）
- [x] 展开后窗口自动调整大小

### FR-3: 账号列表管理

**描述**: 在卡片内管理游戏账号

**验收标准**:
- [x] 显示账号列表
- [x] 支持选择账号
- [x] 支持修改账号别名
- [x] 支持添加新账号
- [x] 支持删除账号

### FR-4: OTP 获取

**描述**: 在卡片内获取 OTP

**验收标准**:
- [x] 显示 OTP 获取按钮
- [x] 点击后获取 OTP
- [x] 自动复制到剪贴板
- [x] 显示获取状态（加载中）
- [x] 3 秒内禁止重复点击

### FR-5: 游戏启动

**描述**: 在卡片内启动游戏

**验收标准**:
- [x] 显示启动游戏按钮
- [x] 支持自动粘贴 OTP 选项
- [x] 未设置路径时提示设置
- [x] 未选择账号时提示选择

### FR-6: 游戏路径设置

**描述**: 为游戏设置启动路径

**验收标准**:
- [x] 检测游戏是否已安装
- [x] 未安装时显示设置路径按钮
- [x] 支持手动选择游戏可执行文件
- [x] 自动保存路径到配置

## 技术实现

### 组件结构

```
AccountList.vue
└── GameCardFull.vue (v-for)
    ├── 头部 (始终显示)
    │   ├── 游戏封面
    │   ├── 游戏名称
    │   ├── 账号数量
    │   └── 展开/收起箭头
    └── 内容 (展开时显示)
        ├── 路径设置提示 (未安装时)
        └── 账号区域 (已安装时)
            ├── 账号列表
            ├── 添加账号按钮
            ├── OTP 区域
            ├── 自动粘贴选项
            └── 启动游戏按钮
```

### 数据流

```
登录成功
    │
    ▼
加载游戏列表 (list_games)
    │
    ▼
展示游戏卡片 (默认收起)
    │
    ▼
用户点击展开
    │
    ▼
检测游戏路径
    │
    ├── 未安装 → 显示路径设置
    │
    └── 已安装 → 加载账号列表
                │
                ▼
            展示账号列表
                │
                ▼
            用户操作 (获取OTP/启动)
```

## 性能考虑

### 延迟加载

- 游戏列表一次性加载
- 账号列表按需加载（展开时）
- OTP 只在用户点击时获取

### 缓存策略

- 游戏路径缓存 5 分钟
- 账号列表不缓存（实时获取）

## 安全考虑

### OTP 调用限制

- 前端防抖：3 秒间隔
- 后端限流：5 次/分钟
- 防止频繁调用导致封号
